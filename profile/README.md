# Show what you shipped.

Showship reads your git commits, pull requests, code reviews and tasks, then builds the progress deck your manager, client or CTO can follow. It runs inside your AI coding agent, on your machine. There is no Showship server and no account.

```bash
npx showship
```

Weekly, per sprint, monthly or for any date range. Works with Claude Code, plus Codex and Antigravity (experimental). Needs Node.js 18 or newer, git and the GitHub CLI. Beta release.

## What you get

- An editable PowerPoint deck with progress, owners, blockers, decisions needed and next steps.
- Plain language for business readers, or a technical version for engineers.
- Tasks from Jira, Linear, Asana, ClickUp or Lark, and any other tool through an MCP server.
- Twelve slide layouts and six designs, with your logo and colours.
- Numbers, owners and dates come from your data or from you. Showship does not invent them.

Showship is in beta, and the task tracker and Codex or Antigravity installs have seen the least testing. If something breaks or a slide looks wrong, [open an issue](https://github.com/Soe-Moe/showship/issues) with what you ran and what you expected.
